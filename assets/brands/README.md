# Marcas y conectores

No se incluyeron logotipos de terceros en esta iteración. Los activos oficiales
no pudieron descargarse y no se sustituyen por imitaciones. La interfaz usa
cápsulas textuales accesibles con el nombre de cada producto, conforme a la
especificación de `docs/design-tokens.md` cuando no existe un activo aprobado.

Antes de incorporar un logo, guárdalo localmente en esta carpeta y registra su
URL de guía de marca, permiso de uso y licencia. Una fuente prevista es
Simple Icons (CC0 1.0): https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md
