# Registro de iconografía y marcas

Este rediseño no distribuye archivos de marcas de terceros. ChatGPT, Claude,
Gemini, Google Workspace, Slack, Notion, Asana, Canva, Android e iOS se
identifican mediante texto visible, no mediante una imitación gráfica.

La referencia elegida para una futura descarga local es Simple Icons, licencia
CC0-1.0: https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md.
Cada archivo incorporado deberá añadir aquí su nombre, URL de origen y fecha de
verificación. Las marcas siguen sujetas a las políticas de sus propietarios.
